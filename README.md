# Hummely 旋律 Agent

Hummely 是一款面向非专业音乐创作者的 AI 旋律工具。用户只需哼唱或导入一段录音，产品会将它转换为可编辑曲谱，并通过可解释的旋律 Agent 完成移调、节奏整理、尾音调整和试听配置。

## 产品问题

大量用户能够哼出旋律，却无法使用专业 DAW 或乐理语言把灵感保留下来。Hummely 将高门槛的“音高识别—节奏整理—曲谱修正—乐器试听”链路，收敛为一条移动端创作流程。

## Agent 如何工作

```text
用户创作目标
      ↓
Observe：读取音域、BPM、时值、乐句和收尾
      ↓
Plan：将目标映射为可执行、可撤销的工具计划
      ↓
Approval：向用户展示观察、置信度和预期改动
      ↓
Act：调用移调、尾音、节奏预览、音色、演奏方式工具
      ↓
Review：对比执行前后的音域与时值，记录工具调用
      ↓
试听 / 撤销 / 继续修改
```

当前 Agent 采用本地、可解释的领域规划器，不将用户音频上传。它不会将尚未实现的和弦或伴奏生成伪装成可用能力。

## 关键产品决策

- **Human-in-the-loop**：Agent 先展示计划，得到明确确认后才修改作品。
- **预览与正式数据分离**：节奏量化先生成 A/B 试听预览，不覆盖用户原始节奏。
- **可逆性**：Agent 执行前保存旋律、节奏、音色和演奏方式快照，支持一键撤销。
- **降级策略**：Basic Pitch 不可用时，使用本地 YIN 音高检测保证主链路可用。
- **可观测性**：保留原始识别事件、音符合并理由、边界决策、Agent 工具调用和结果复核。

## 技术与能力

- React + Vite 移动端 PWA
- Spotify Basic Pitch 端侧音高与起音推理
- 人声起音、气口、颤音与滑音后处理
- 简谱 / 五线谱、节奏量化预览与手动音符编辑
- 钢琴、木琴采样音色与连奏 / 断奏试听
- IndexedDB 本地作品库与识别诊断数据
- 本地旋律 Agent：目标理解、工具规划、人工确认、执行、复核与撤销

## 演示路径

1. 哼唱 4–12 秒旋律，完成识别。
2. 在曲谱页修正一个音，对比原始人声与乐器试听。
3. 进入“AI 编曲”，输入：“让这段旋律更舒缓，用钢琴连奏，并延长尾音”。
4. 讲解 Agent 观察、置信度、工具计划和确认门。
5. 执行计划，试听结果，展示节奏预览没有覆盖正式曲谱。
6. 一键撤销，证明 Agent 操作可逆。
